 Mavu Clothing Store - Formative Part 1 and Part 2

This is a simple website for Mavu Clothing Store located in Thohoyandou.

 Project Description
Mavu Clothing Store sells affordable and stylish clothes for men, women and kids. This website was created for WEDE5020 Formative Assessment 1 and 2.

The purpose of part 2 is to improve part 1

 Pages Included
- `index.html` - Home page with welcome message
- `about.html` - About the business history
- `products.html` - List of products and prices
- `enquiry.html` - Enquiry form for customers
- `contact.html` - Contact details


Mavu Clothing store part 2
> Created external style sheet CSS which links to all pages for styling 
> Responsive designs, Flexbox and media queries were used to make the website friendly
> Added images for clothes and for a logo
> Color scheme background applied
> Navigation bar from one page to another working
