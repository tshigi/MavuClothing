 Mavu Clothing Store - Formative 1

This is a simple website for Mavu Clothing Store located in Polokwane.

 Project Description
Mavu Clothing Store sells affordable and stylish clothes for men, women and kids. This website was created for WEDE5020 Formative Assessment 1.

 Pages Included
- `index.html` - Home page with welcome message
- `about.html` - About the business history
- `products.html` - List of products and prices
- `enquiry.html` - Enquiry form for customers
- `contact.html` - Contact details
